# 文章默认封面：外链随机图 + 前端每次刷新随机

Status: accepted

文章未手动设置封面时，Butterfly 主题通过 `random_cover.js` 从 `default_cover` 图库自动分配一张。此前图库只配了 1 张固定 picsum 图，导致所有文章封面相同、重复度高。

决策：
1. 默认图库使用外链 **picsum.photos**（而非本地图库）。理由：图源海量、零图库管理、每次刷新都新鲜；代价是国内访问可能较慢，若日后加载过慢可切回本地图库（改动很小）。
2. 随机时机选 **前端每次刷新随机**（而非 `random_cover.js` 生成时固定分配——后者原生支持数组随机、成本更低）。理由：用户明确要"每次进入都有新鲜感"；代价是需维护约 15–25 行前端 JS。
3. **只有未手动设置封面的文章走随机**：默认图统一使用 `seed/blog-` 前缀的 picsum URL，前端 JS 只替换命中该前缀的封面；手动封面（本地 `/img/` 或其他 URL）永远不被替换，优先显示。
4. 覆盖范围：首页列表封面、侧边栏"最近文章"缩略图、文章详情页顶部大图三处。
